# Novion Music Player

PWA Music Player powered by YouTube Data API v3

## Setup

1. Clone repo
2. Copy .env.local.example ke .env.local
3. Isi semua YOUTUBE_API_KEY_1 sampai YOUTUBE_API_KEY_10
4. npm install
5. npm run dev

## Deploy ke Vercel

1. Push ke GitHub
2. Import di vercel.com
3. Tambahkan Environment Variables:
   - YOUTUBE_API_KEY_1 sampai YOUTUBE_API_KEY_10
4. Deploy

## Fitur
- 🎵 Stream musik dari YouTube
- 🔍 Search dengan filter konten musik
- 📱 PWA - bisa diinstall
- 🎨 8 tema warna
- ❤️ Liked songs & History
- 📚 Custom playlists
- 📤 Import/Export playlist
- 🔑 10 API key rotation otomatis
